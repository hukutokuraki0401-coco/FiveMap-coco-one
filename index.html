📖 作図マップツールの使い方

1. アイコンの配置

  • 左側ツールバーの「マーカー配置」ボタンにマウスを乗せると、アイコン一覧（警察・EMS・ギャング・車両など）が右側に展開します。
  • 設置したいアイコンをクリックすると配置モードになり、マップ上をクリックして配置できます。
  • 直近設定の自動記憶: アイコンごとに最後に使った「色」や「サイズ」が記憶され、次回選択時に自動復元されます。

2. 名前ラベル と 詳細メモ

  • 名前（ラベル）: マップ上に常時表示される短いテキスト（「本署前」「作戦地点A」など）。
  • 詳細メモ: ピンをクリックした時だけ読める詳細情報（無線周波数、作戦指示、メンバー配置など）。改行も可能です。
  • 複数同時表示: ピンをクリックして開いた詳細ポップアップは、他のピンをクリックしても閉じずに同時に開いたまま閲覧できます。
  • 一括消去: ツールバーの「❌ ポップアップ全閉」ボタンを押すか、「ラベル常時表示」に切り替えると、開いているポップアップを一度に閉じることができます。

3. コピー＆ペースト（複製機能）

  • マップ上のピンをクリックすると、オレンジ色の枠線が表示されて選択状態になります。
  • Ctrl + C（Mac: Cmd + C）で選択中のピンをコピー。
  • Ctrl + V（Mac: Cmd + V）で、現在のマウスカーソル位置に同一設定（アイコン・色・名前・メモ）で複製配置されます。

4. 移動・編集・削除

  • 通常時はピンをそのままドラッグして自由に位置を動かせます。
  • 「✏️ 編集モード: ON」に切り替えてピンをクリックすると、名前・メモ・色・サイズ・アイコン形状を後から変更できます。
  • 左ツールのゴミ箱アイコンで配置済みオブジェクトを削除できます。

5. データの保存と画像出力

  • フォルダに保存: ローカルフォルダ内にマップ画像と作図データ（data.json）を丸ごと保存します。
  • 画像として出力: 作成した作戦マップを高解像度PNG/JPGでワンクリック保存できます。
